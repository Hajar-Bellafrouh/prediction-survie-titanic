# Projet Machine Learning – Prédiction de survie sur le Titanic

Projet de Machine Learning (ENSA Khouribga). Détails dans [`titanic/README.md`](titanic/README.md).

## Structure

```
Projet_ML/
├── titanic/
│   ├── data/                     # train.csv, test.csv, gender_submission.csv
│   ├── notebooks/titanic_survival_prediction.ipynb
│   ├── outputs/submission.csv
│   └── README.md
├── requirements.txt
└── README.md
```

## Installation

```bash
pip install -r requirements.txt
cd titanic/notebooks
jupyter notebook
```

Lancez Jupyter depuis `titanic/notebooks/` : les chemins sont relatifs à ce dossier.
